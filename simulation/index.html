PERSPECTIVE
A LITTLE COSMIC CONTEXT

Gravity, with a little direction.

A rotating 3D cloud cools and contracts into a disk. Particles feel sampled mutual gravity, a smooth dark-matter halo, and a rotating two-arm spiral potential.

The spiral potential models a density wave; gas damping helps particles collect along its arms. This is an accelerated, illustrative galaxy model, not a scientific prediction of galaxy formation.

WebGL2 shaders initialize and integrate every particle on the GPU. Adaptive mode adjusts the actual simulated population toward 60 FPS. Hardware, display refresh rate, and browser load set the practical limit. Full perf rapidly increases the population until FPS falls, then backs off to the last smooth count. Buffers grow as needed; there is no fixed particle cap, but GPU memory and WebGL texture limits still apply. GPU timing shows work separately from display frame time.
